# techNews

매일 올라오는 정형화된 기술 뉴스 이슈를 Markdown 문서로 자동 보관하는 저장소입니다.

## 이슈 형식

각 아티클은 다음 형태의 3단계 분류 헤더 아래에 둡니다.

```md
## 대분류 > 중분류 > 소분류

### [아티클 제목](https://example.com/article)

- **한줄 요약:** ...
- **기술 자료인 이유:** ...
```

## 문서 저장 구조

요청한 경로 순서인 **대분류 / 소분류 / 중분류** 로 저장합니다.

```text
docs/
└── <대분류>/
    └── <소분류>/
        └── <중분류>/
            └── YYYY-MM-DD-issue-NN-XX-<slug>.md
```

예를 들어 이슈의 헤더가

```text
AI 연구 > 에이전트 > 하네스 최적화
```

이면 문서는 다음 아래에 생성됩니다.

```text
docs/AI 연구/하네스 최적화/에이전트/
```

각 생성 문서에는 원본 이슈 번호/URL, 날짜, 대·중·소분류, 원문 링크를 front matter로 기록합니다.

## 자동화

`.github/workflows/archive-issues.yml` 이 다음 시점에 실행됩니다.

- 이슈 생성
- 이슈 수정
- 이슈 재오픈
- 수동 실행(`workflow_dispatch`)

이슈가 수정되면 해당 이슈에서 이전에 생성된 문서를 먼저 제거하고 다시 생성하므로, 분류 경로가 바뀌어도 오래된 파일이 남지 않습니다.

수동 실행에서는 이슈 번호를 입력해 과거 이슈도 다시 아카이브할 수 있습니다.
