# Efficient Benchmarking in Production: A Study of an Evolving LLM Agent

> 원문: [https://arxiv.org/abs/2609.21267](https://arxiv.org/abs/2609.21267) · [GitHub Issue #2](https://github.com/8silvergun/techNews/issues/2)

- **한줄 요약:** 수만 명의 월간 사용자가 쓰는 분석 에이전트의 과거 574회 평가를 이용해 샘플링·캐시·고정 하위집합·IRT 적응형 테스트를 비교하고, 전체의 38.5%인 200문항으로 1.03%p MAE를 달성했습니다.
- **기술 자료인 이유:** 실제 프로덕션 에이전트의 시간순 보정/홀드아웃 데이터로 평가 비용과 정확도를 정량 비교하며, 수치상 최적인 IRT 대신 운영이 단순한 난이도 층화 고정 하위집합을 배포한 판단까지 설명합니다.
