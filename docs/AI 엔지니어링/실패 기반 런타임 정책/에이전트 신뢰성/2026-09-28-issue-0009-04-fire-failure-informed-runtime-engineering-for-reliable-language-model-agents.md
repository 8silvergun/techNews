# FIRE: Failure-Informed Runtime Engineering for Reliable Language-Model Agents

> 원문: [https://arxiv.org/abs/2609.26048](https://arxiv.org/abs/2609.26048) · [GitHub Issue #9](https://github.com/8silvergun/techNews/issues/9)

- **한줄 요약:** 모델 가중치를 바꾸지 않고 실패 직전 상태에서 하네스가 짧은 지시나 행동 거부를 적용해, 이미 풀 수 있는 코딩 과제를 안정적으로 끝내게 합니다.
- **기술 자료인 이유:** Terminal-Bench 2.1의 설치 가능한 87개 과제를 동일 조건으로 비교했고, GPT-5.6 Sol의 2회 반복 성공률이 64.4%→73.6%로 올랐습니다. 무정책·개입 시점만 맞춘 가짜 지시·일반 재검토를 포함한 5군 실험으로 정책 내용의 효과를 구분하려고 합니다.
