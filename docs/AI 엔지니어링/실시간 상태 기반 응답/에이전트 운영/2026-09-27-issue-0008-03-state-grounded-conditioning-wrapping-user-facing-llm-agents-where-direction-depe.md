# State-Grounded Conditioning: Wrapping User-Facing LLM Agents Where Direction Depends on Live State

> 원문: [https://arxiv.org/abs/2609.27606](https://arxiv.org/abs/2609.27606) · [GitHub Issue #8](https://github.com/8silvergun/techNews/issues/8)

- **한줄 요약:** 현재 게임·세션 상태를 구조화해 인식·근거·상호작용 래퍼에 나눠 전달함으로써, 질문에는 답해도 실제 사용자 상태와 어긋나는 에이전트의 방향 이탈을 줄입니다.
- **기술 자료인 이유:** 익명화한 200개 게임 코칭 세션, 약 1,000개 모델 턴에서 응답 지연과 사람 주석 기반 대화 품질을 측정했고, 세 래퍼 적용 시 세션 단위 상태 근거 정확도가 가장 강한 비교군의 26.5%에서 83.5%로 올랐습니다. 특정 게임 코칭 환경의 결과이며 래퍼별 독립 효과는 입증하지 않습니다.
