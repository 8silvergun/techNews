# RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

> 원문: [https://arxiv.org/abs/2609.24972](https://arxiv.org/abs/2609.24972) · [GitHub Issue #3](https://github.com/8silvergun/techNews/issues/3)
