# AgentWorld: Benchmarking Long-Horizon Collaboration of Multi-agent LLMs

> 원문: [https://arxiv.org/abs/2609.31590](https://arxiv.org/abs/2609.31590) · [GitHub Issue #12](https://github.com/8silvergun/techNews/issues/12)

- **한줄 요약:** 역할과 능력이 서로 다른 3~20개 에이전트가 50회 넘게 협력해야 하는 환경에서, 최종 성공뿐 아니라 각 행동의 실제 기여도까지 평가합니다.
- **기술 자료인 이유:** 사람이 주석한 100개 과제와 100개 변형, 그래프 기반 Causal Collaboration Effectiveness 지표, 네 모델의 성공률·의사소통 실패 분석을 공개합니다. 최고 모델도 이 샌드박스 과제 성공률이 52.0%라고 보고하며 코드·데이터를 공개합니다.
