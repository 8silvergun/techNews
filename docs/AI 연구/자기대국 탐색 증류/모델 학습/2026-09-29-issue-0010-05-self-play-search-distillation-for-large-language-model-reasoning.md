# Self-Play Search Distillation for Large Language Model Reasoning

> 원문: [https://arxiv.org/abs/2609.30936](https://arxiv.org/abs/2609.30936) · [GitHub Issue #10](https://github.com/8silvergun/techNews/issues/10)

- **한줄 요약:** 보드게임 자기대국 탐색에서 최선 수·대안·상대 응수·가치 추정을 뽑아 추론 데이터로 증류하고, 수학 등 학습하지 않은 과제로 전이되는지 시험합니다.
