# CodeMidas: Scaling Agentic Coding RL Environments from Code Itself

> 원문: [https://arxiv.org/abs/2609.22068](https://arxiv.org/abs/2609.22068) · [GitHub Issue #2](https://github.com/8silvergun/techNews/issues/2)

- **한줄 요약:** 이슈·커밋에 의존하지 않고 기존 소스 코드만으로 행동 명세, 실행 기반 테스트, 검증 가능한 RL 과제를 생성해 3,185개 리포에서 5,545개 훈련 과제를 만들었습니다.
- **기술 자료인 이유:** 23개 언어·15개 도메인의 데이터 생성 파이프라인과 실행 검증을 제시하고, GRPO 훈련 후 DeepSWE +11.7%, ProgramBench +17%, Terminal-Bench +8.5% 등 다섯 벤치마크의 향상을 보고합니다.
